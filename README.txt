CHESS VS STOCKFISH (installable web app)

Deploy from a phone, free:
1. Netlify: app.netlify.com/drop  -> drop the unzipped folder (or use a computer for drag-and-drop).
   Or GitHub: create a repo, upload all these files, then in Netlify choose "Import from Git"
   (build command: none, publish directory: /).
2. Open your Netlify link in Chrome on Android -> menu (3 dots) -> "Install app" / "Add to Home screen".
3. It then opens as its own app, works offline, and your game is auto-saved.
